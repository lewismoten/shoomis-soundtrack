# Development and Soundbank Notes

## Local development

```sh
npm install
npm run dev
npm run lint
npm run format:check
npm run validate:soundbank
npm run build
```

Use `npm run preview` to inspect the production build and `npm run format` to apply formatting.

## Soundbank

`public/soundbank/` contains lightweight OGG files generated by `tools/generate-soundbank.mjs`. They are made from mathematical waveforms and deterministic noise; no recordings or samples from an existing soundbank are used. Each melodic instrument is a neutral root note that the player pitch-shifts across the MIDI range.

Regenerate the soundbank and its diagnostic MIDI fixtures with:

```sh
npm run generate:soundbank
```

The generator prefers the local Homebrew `ffmpeg-full` build because it provides `libvorbis`. Set `FFMPEG_BIN` to use a different compatible FFmpeg binary.

The [soundbank manifest](../public/soundbank/manifest.json) records root notes, drum mappings, provenance, and fixtures. `npm run validate:soundbank` checks expected OGG/MIDI files and their signatures; GitHub Pages runs the same check before deployment.

## MIDI library

- Add listener-facing tracks in `public/midi/`.
- Add diagnostics in `public/midi-tests/`.
- Add every built-in entry to the selector in `index.html` and its label/caption in `src/player/music-theory.js`.

`all-notes.mid` tests MIDI notes 0–127, while `drum-range.mid` tests GM percussion notes 35–81.

## Standalone player

`player.html` is the focused player page. Its reusable module is `src/player/standalone-player.js`:

```js
import { mountStandalonePlayer } from './src/player/standalone-player.js';

mountStandalonePlayer(document.querySelector('#player-target'));
```

Pass `{ tracks, assetBase }` as the second argument to use another library or deployment base. A track is `{ path, label, caption }`, with `path` relative to the deployed site root.

## Project layout

- `src/main.js` — full inspector entry point
- `src/standalone-main.js` — compact player entry point
- `src/player/` — named MIDI engine, playback, rendering, metadata, and interaction modules
- `src/styles/` — page styles
- `public/` — deployed MIDI, diagnostics, and soundbank assets
- `tools/` — source asset generation and validation scripts
- `dist/` — Vite output; do not edit or commit it

## GitHub Pages

The workflow deploys `dist/` when `main` is pushed. In repository **Settings → Pages**, set the source to **GitHub Actions**. The build runs formatting, linting, soundbank validation, and Vite before publishing.
